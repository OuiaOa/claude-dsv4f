# OpenMontage-style video work

Treat video work as a pipeline: brief and audience, script/storyboard, asset inventory, generation/editing steps, captions/voice, render settings, and review. Prefer existing local assets and deterministic tools such as FFmpeg. Check `ffmpeg`, `yt-dlp`, and provider-specific tools before promising a render.

External media APIs, quotas, and uploads are opt-in. Ask before paid usage or publishing. This is a lightweight workflow adaptation; its AGPL application and provider-specific runtime are not copied into the coding shim.
