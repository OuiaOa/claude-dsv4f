# Composio integrations

Check `composio --help` or the configured MCP server before using it. Confirm the target app, account, scope, and whether the action is read-only or has side effects. Ask for approval before sending, deleting, publishing, purchasing, or changing data.

If absent or unauthenticated, explain the setup requirement and offer a local/read-only alternative. Never paste tokens into prompts or claim an external action succeeded without inspecting the tool result.
