# Nova-style YouTube workflow

Before recommending a video, check existing published, approved, rejected, filmed, and scheduled ideas; gather channel and competitor evidence; identify the audience and goal; then propose an idea with receipts. For a script, include hook, proof, retention structure, caveats, shot/asset notes, and a practical filming plan. For an upload package, include title variants, description, chapters, thumbnail concept, and pinned comment.

Use Agent Reach/YouTube tools when available and cite source videos. Do not claim access to analytics or publish anything without authenticated tools and explicit approval. This is a portable workflow adaptation, not an OpenClaw/Hermes runtime.
